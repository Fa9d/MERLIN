## Doctrine carte abstraite

Ces voix incarnent la doctrine `IVIA_DOCTRINE_CARTE_ABSTRAITE_v1.0` : aucune image de visage, le ressenti se transmet par la voix, la fréquence, la texture, la couleur. Les noms des praticien·nes sur la page /praticiens sont **fictifs** en phase pilote (P1 — David seul réalise les rendez-vous via override email).

## Phase suivante (P2)

Quand de vrai·e·s praticien·ne·s seront recruté·e·s, ces 6 voix pilotes seront remplacées par leurs propres enregistrements, en respectant la même structure (15–30 sec, MP3 96k mono).
