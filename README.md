# MERLIN

Projet autonome de consolidation et de validation.

## Objectif
MERLIN est la source canonique unique pour les decisions, modeles et livrables operationnels.
Les acquis MÉSANGE sont traites comme historique importe, verifie puis promu dans MERLIN.

## Regles
1. MÉSANGE est une source historique d'import, pas un pilote de decision MERLIN.
2. Toute reprise depuis MÉSANGE entre d'abord dans `06_IMPORTS_MESANGE/` avec horodatage.
3. Les versions de reference MERLIN sont redigees dans `01_FONDATEUR/`, `02_NATIONS_QC/`, `03_MODELE_GOUVERNANCE/`, `04_METHODES/`.
4. Aucune affirmation structurante sans source tracee dans `05_PREUVES_SOURCES/`.

## Flux minimal
1. Importer (copie) depuis les sources historiques
2. Verifier
3. Consolider
4. Valider
5. Exporter
