# MERLIN — Architecture de Plateforme Évolutive
**Version 1.0 — 25 juin 2026**

## Principe fondateur

MERLIN n'est pas un produit. C'est une plateforme — un système d'exploitation pour l'accompagnement humain. Comme un OS accepte des applications inconnues au moment de sa conception, MERLIN accepte des modules futurs que nous ne pouvons pas encore nommer.

## Les 3 invariants

Ces trois éléments ne changent jamais, quelle que soit l'évolution du projet.

### Invariant 1 — La doctrine IVIA
Les 7 principes fondateurs sont le filtre de tout. Chaque module, partenaire, fonctionnalité doit les respecter. Si un développement contredit la doctrine, il ne rentre pas.

### Invariant 2 — Le pipeline de données gouverné
Le pipeline en 8 étapes (consentement → capture → effacement → anonymisation → structuration → synthétisation → vectorisation → activation) est la colonne vertébrale. On ne le reconstruit jamais. On l'étend.

### Invariant 3 — L'architecture modulaire
Chaque marché, chaque usage, chaque langue, chaque communauté est un module indépendant. Un module se connecte à la plateforme sans la modifier.

## Protocole de connexion d'un nouveau module

Un module peut entrer dans MERLIN s'il satisfait les 5 conditions suivantes :
1. Conformité doctrinale (validation par le fondateur)
2. Connexion au pipeline gouverné (pas de pipeline parallèle)
3. Souveraineté des données (les données restent dans la juridiction du module)
4. Réversibilité (un module peut être retiré sans affecter les autres)
5. Documentation (tout module est documenté avant déploiement)

## Vision traduction des langues vivantes

Chaque personne doit pouvoir parler sa langue et être comprise — non par traduction mécanique, mais par traduction qui préserve le sens vivant, les nuances, les épistémologies propres à chaque peuple.

Trajectoire :
- M6-M18 : R&D avec nations autochtones, corpus de langues vivantes
- M18-M36 : Prototype de traduction contextuelle
- M36+ : Intégration temps réel dans les séances

## Ce que cette architecture protège

Le mécanisme interne de MERLIN reste propriétaire. L'architecture est publique. Le moteur ne l'est pas.
