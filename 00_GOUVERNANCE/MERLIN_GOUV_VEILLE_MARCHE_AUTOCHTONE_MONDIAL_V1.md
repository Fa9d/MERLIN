## 3. LE CORPUS DAVID — CONTENU ET PERTINENCE

### 3.1 Les Sept Enseignements des Aînés (Seven Grandfather Teachings)

Énseignements fondamentaux de plusieurs nations algonquiennes (Anishinaabe / Ojibwé) :

| Enseignement | Mot en Ojibwé | Description |
|--------------|---------------|-------------|
| Amour | *Zaagi'idiwin* | Aimer sans condition |
| Respect | *Minaadendamowin* | Respecter tout être vivant |
| Courage | *Aakode'ewin* | Faire ce qui est juste |
| Honnêteté | *Gwayakwaadiziwin* | Être vrai avec soi-même |
| Sagesse | *Nibwaakaawin* | Utiliser les dons responsablement |
| Humilité | *Dbaadendiziwin* | Se savoir égal aux autres |
| Vérité | *Debwewin* | Connaître et vivre sa vérité |

**Pertinence IVIA** : Ces sept enseignements sont structurellement cohérents avec la trajectoire MÉSANGES (écoute → clarification → autonomie). Ils pourraient servir de cadre pédagogique pour un module autochtone.

### 3.2 Cercles de parole / Cercles de guérison

Pratique répandue dans de nombreuses nations autochtones nord-américaines :
- Espace de parole non hiérarchique, tour de parole réglé
- Bâton de parole ou objet symbolique
- Confidentialité collective
- Processus de guérison communautaire

**Pertinence IVIA** : Le cercle de parole est une forme d'accompagnement collectif profondément compatible avec les valeurs MÉSANGES. Une version numérique ou hybride (groupe de 6–8 personnes + praticien) pourrait constituer un format de séance groupe à explorer.

### 3.3 Intendance autochtone

Concept d'intendance (*stewardship*) : responsabilité envers la terre, la communauté, les générations futures. Notion d'appartenance sans possession.

**Pertinence IVIA** : Écho direct à l'anti-dépendance doctrinale d'IVIA (la personne repart avec sa propre capacité renforcée, elle n'appartient pas à la plateforme).

## 4. OPPORTUNITÉ STRATÉGIQUE — 3 AXES

### Axe A : IVIA OBNL — Déploiement en communauté autochtone QC

**Hypothèse** : IVIA OBNL obtient un financement (CRSH, ISC, fondations) pour déployer MÉSANGES dans des communautés des Premières Nations au Québec.

**Avantages** :
- Marché sous-servi avec besoin documenté (détresse élevée, accès aux soins limité)
- Financement public disponible (Initiative de santé mentale des communautés autochtones — ISC)
- Différenciateur marché fort
- Cohérence doctrinale parfaite

**Risques** :
- Appropriation culturelle si mal cadré — besoin d'un partenariat communautaire authentique
- Délais de construction de confiance longs (communautés autochtones méfiantes, à juste titre, des initiatives extérieures)
- Langue et contexte culturel très spécifiques

**Prérequis** : Un partenaire autochtone co-développeur (nation, organisation, praticien autochtone).

### Axe B : Format Cercle de parole numérique

**Hypothèse** : MÉSANGES développe un format de séance groupe (6–8 personnes) inspiré du cercle de parole, animé par un praticien certifié.

**Avantages** :
- Accessibilité économique (coût par personne réduit)
- Réduction de l'isolement (problème documenté dans les données QC)
- Format différenciateur sur le marché des apps de bien-être

**Risques** :
- Complexité technique (salle virtuelle multi-participants)
- Risque de mauvaise appropriation de la pratique autochtone si non co-construit

### Axe C : Expansion internationale — Peuples autochtones en Amérique latine

**Hypothèse** : À horizon 5 ans, IVIA inc. adapte MÉSANGES pour les communautés autochtones d'Amérique latine (Mexique, Bolivie, Pérou) via IVIA OBNL.

**Marché** : 45–50 millions de personnes, accès aux soins extrêmement limité, soutien d'organisations internationales (OPS, Banque mondiale, ONU).

**Statut** : Très long terme. À réexaminer si l'axe A est validé et déployé avec succès.
