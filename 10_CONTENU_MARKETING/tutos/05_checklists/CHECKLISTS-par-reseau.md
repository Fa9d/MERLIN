# Check-lists de publication par réseau

À dupliquer pour **chaque** contenu. Coche au fur et à mesure.
Nom du contenu : ________________________  ·  URL blog : ________________________

---

## ✅ Check-list générale (avant tout)
- [ ] Angle défini (1 phrase)
- [ ] Fiche de production remplie
- [ ] Sujet sensible ? → ressources d'aide prêtes (1 866 APPELLE / 277-3553, texto 535353, suicide.ca, 988, 911)
- [ ] Visuels produits et relus (aucun texte coupé, contraste OK)
- [ ] Lien blog testé (répond 200) + UTM si utilisé
- [ ] Ton de marque respecté (posé, non clinique, fr-CA)

---

## 🔵 LinkedIn
- [ ] Accroche forte en 1re ligne (avant « …voir plus »)
- [ ] 900-1 500 caractères, aéré (retours à la ligne)
- [ ] 1 statistique/fait crédible cité
- [ ] 3-5 hashtags pertinents en fin
- [ ] Lien vers l'article (en fin ou 1er commentaire)
- [ ] Visuel horizontal 1200×627 OU carré 1080×1080
- [ ] Texte alternatif sur l'image
- [ ] Programmé mardi ou jeudi, 8 h-10 h

## 🔵 Facebook
- [ ] Accroche empathique / question d'ouverture
- [ ] 400-800 caractères, ton chaleureux
- [ ] Lien en clair (aperçu vérifié)
- [ ] 2-3 hashtags max
- [ ] Visuel 1080×1080 ou 1200×630
- [ ] Texte alternatif sur l'image
- [ ] Programmé midi ou 18 h-20 h

## 🟣 Instagram
- [ ] Message tient dans le visuel (carrousel 4-6 slides ou citation)
- [ ] Slides 1080×1080, cohérence visuelle
- [ ] Caption 300-600 car. avec CTA « Lien en bio »
- [ ] Lien en bio à jour (Linktree/URL directe)
- [ ] 8-15 hashtags (mix large + niche) en fin ou 1er commentaire
- [ ] Texte alternatif renseigné
- [ ] Slide finale = CTA + logo
- [ ] Programmé midi ou soir

## ⚫ X / Twitter
- [ ] Post unique ≤ 280 car. OU fil de 3-5 tweets
- [ ] Accroche chiffrée / percutante
- [ ] 1-2 hashtags intégrés
- [ ] Lien dans le dernier tweet
- [ ] Visuel 1600×900 (option)
- [ ] Texte alternatif sur l'image
- [ ] Programmé matin

## ⚫ TikTok
- [ ] Hook dans les 2 premières secondes
- [ ] Vidéo 20-45 s, verticale 1080×1920
- [ ] Une seule idée développée
- [ ] Sous-titres / texte à l'écran
- [ ] Voix off claire (script suivi)
- [ ] CTA final (« Plus de repères en bio »)
- [ ] Caption courte + 3-5 hashtags
- [ ] Son/musique conforme (droits)
- [ ] Programmé soir
