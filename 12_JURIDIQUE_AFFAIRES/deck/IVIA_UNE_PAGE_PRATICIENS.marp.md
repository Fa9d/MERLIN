# Votre pratique d'écoute, enfin outillée

*IVIA — la maison du vivant.* — **Une infrastructure complète pour praticiennes et praticiens d'écoute. Gratuite pendant le pilote.**

## Le quotidien que vous connaissez

Un agenda ici, les paiements par virement là, les séances sur une plateforme vidéo générique, les notes dans un document texte… et aucune garantie sur la confidentialité des données de vos clients.

## Ce qu'IVIA remplace, en un seul espace

| Fonction | Ce que vous obtenez |
|---|---|
| Prise de rendez-vous | Vos créneaux en ligne, réservation autonome par le client |
| Paiement | Encaissement intégré, reçus automatiques |
| Séance | Salle audio/vidéo privée, sans installation pour le client |
| Notes de séance | Brouillons assistés par IA — **rien ne part sans votre validation** |
| Documents client | Reformulations livrées dans l'espace sécurisé du client |
| Confidentialité | Données au Québec, transcription locale — conforme **Loi 25** |
