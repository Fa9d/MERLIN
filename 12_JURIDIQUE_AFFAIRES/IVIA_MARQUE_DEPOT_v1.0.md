## 1. Ce qu'on dépose

| Type de marque | Contenu | Pourquoi |
|---|---|---|
| **Verbale (mot)** | `IVIA` | Protège le nom quelle que soit la typo/couleur |
| **Figurative (logo)** | le carré à 3 barres | Protège le visuel |
| *(optionnel)* **combinée** | logo + « IVIA » | Si on veut protéger l'ensemble verrouillé |

Recommandation : déposer **la verbale + la figurative séparément** (protection plus large).
*(Penser aussi à « MÉSANGES » si la marque-fille doit être protégée — dossier distinct.)*

## 2. Classes de Nice recommandées (à confirmer)

IVIA est **non clinique** (Loi 21) : **éviter la classe 44 (services médicaux)**.

| Classe | Couvre | Pertinent IVIA |
|---|---|---|
| **42** | Logiciel-service (SaaS), plateforme, hébergement | ✅ la plateforme |
| **41** | Éducation, formation, publication de contenu | ✅ Ressources / formations / articles |
| **45** | Services personnels et sociaux, soutien, accompagnement (non médical) | ✅ l'accompagnement IVIA |

→ **3 classes** : 42 · 41 · 45.

## 3. Coûts (Canada — CIPO/OPIC, en ligne, estimations 2026 à valider)

| Poste | Montant (CAD) |
|---|---|
| Dépôt 1re classe | ≈ 458 $ |
| Chaque classe additionnelle | ≈ 139 $ |
| **Taxes gouv. pour 3 classes** | **≈ 736 $** *(458 + 2×139)* |
| Recherche de disponibilité (clearance) | 0–500 $ (selon agent / faite à l'interne) |
| Honoraires agent·e de marques (recherche + rédaction + dépôt) | ≈ 500–2 000 $ (optionnel mais conseillé) |
| **Total réaliste Canada (1 marque, 3 classes, avec agent)** | **≈ 1 200–2 700 $** |

- 2e marque (la figurative) : ajouter ~les mêmes taxes (≈ 736 $ pour 3 classes) + honoraires réduits si déposée en même temps.
- **International (plus tard)** : USA (USPTO, TEAS) ≈ 250–350 USD/classe ; multi-pays via **Protocole de Madrid** (OMPI) — taxe de base ≈ 653 CHF + taxes par pays.

## 4. Démarche & échéancier

1. **Recherche de disponibilité** (CIPO + Web + noms commerciaux) — éviter un refus/opposition.
2. **Dépôt** (verbale + figurative), description des produits/services par classe.
3. **Examen CIPO** : long — compter **18–30 mois** actuellement.
4. **Publication** au Journal des marques → délai d'**opposition** (2 mois).
5. **Enregistrement** : valable **10 ans**, renouvelable.
