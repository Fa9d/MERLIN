## Règles de tenue

1. **Un geste = une ligne datée**, consignée le jour même dans la fiche de l'organisme (le plus récent EN HAUT).
2. **Statuts** : `à préparer` → `prêt` → `envoyé` → `en échange` → `conclu` / `clos sans suite`. Une relance est due **J+10** après un envoi sans réponse (sauf mention contraire).
3. **La vue d'ensemble reflète les fiches**, jamais l'inverse — on met à jour la fiche d'abord.
4. Les pièces envoyées sont nommées par leur chemin dans le dépôt (traçabilité : quelle version est partie).
5. Git est l'historique — pas de copie, pas de duplication dans un outil externe.
