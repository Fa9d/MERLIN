# Dossiers d'envoi — démarches externes

**Créé** : 18 juillet 2026 · **Suivi** : `../IVIA_REGISTRE_DEMARCHES_v1.0.md` (source du statut)

## Structure

Un dossier par organisme, un sous-dossier par cible. Chaque sous-dossier est
**autoportant** : le courriel prêt à copier-coller (destinataire, objet, corps,
pièces) et ses notes d'envoi. Les pièces jointes communes sont à la racine du
dossier de l'organisme (copies des canons — la source reste `deck/` et les
documents canoniques).

```
demarches/
  mila/
    IVIA_PRESENTATION_MILA_v1.0.pdf      ← pièce jointe commune (copie de deck/)
    01_ventures-launchpad/               ← candidature (formulaire, FR + EN)
    02_ravanelli-parole/                 ← courriel technique ASR/prosodie
    03_dumas-sante-mentale/              ← courriel corpus + temporalité décalée
    04_regis-ia-responsable/             ← courriel conformité implémentée
    05_abundant-intelligences/           ← demande de conseil sur la posture ⚠️
```

## Règles

1. **Rien ne part sans relecture du fondateur** — chaque courriel porte un statut
   `RELECTURE : en attente / validé / envoyé le AAAA-MM-JJ`.
2. Chaque envoi et chaque réponse se consignent dans le **registre** (fiche de
   l'organisme) — le dossier d'envoi ne tient pas l'historique, il tient le texte.
3. Le dossier `05` a sa propre note de posture (02_NATIONS_QC) : pas de relance,
   le rythme appartient aux interlocuteurs.
