## Logique d'usage

Ces exemples montrent comment passer:

1. d'une intuition ou d'un probleme
2. a une formalisation dans le bon registre
3. puis a une revision de methode
4. puis a une mesure de l'impact du changement

---

## Prochaine etape recommandee

Utiliser ces exemples comme base pour les premiers cas reels, puis:
- dater chaque nouvel apprentissage;
- ne pas dupliquer inutilement;
- revoir mensuellement les patterns et les impacts.
