## PRÉAMBULE

### La veille concurrentielle comme exercice doctrinal

La majorité des documents de veille concurrentielle dans les startups servent à identifier les faiblesses des concurrents pour les exploiter et les forces pour les copier. IVIA utilise la veille concurrentielle différemment : pour comprendre ce que le marché fait, ce qu'il ne fait pas, et ce qu'IVIA peut faire que les autres ne peuvent pas faire sans trahir leur propre modèle économique.

La règle de non-commission et le pipeline J+30 ne sont pas copiables par les plateformes dominantes sans détruire leur propre source de revenus. Le moat d'IVIA est doctrinal autant que technologique.

## PARTIE I — CONCURRENTS DIRECTS AU QUÉBEC

### 1.1 Acuity Scheduling (suite de gestion + prise de rendez-vous)

**Profil** : Acuity Scheduling (rachetée par Squarespace) est la solution de prise de rendez-vous en ligne la plus utilisée par les praticiens indépendants au Québec. Elle offre la gestion d'agenda, les paiements en ligne, et les intégrations Zoom/Google Meet pour les séances à distance.

**Analyse SWOT — Acuity**

| Forces | Faiblesses |
|---|---|
| Marque reconnue, base installée massive | Aucun outil de documentation de séance |
| Interface intuitive, courbe d'apprentissage faible | Pas de pipeline de données éthique |
| Intégration avec des dizaines d'outils | Données hébergées aux États-Unis |
| Tarification accessible (~14-25 USD/mois) | Aucune doctrine sur l'éthique des données |
| Support client réactif | Conçu pour le commerce, pas pour l'écoute |

| Opportunités | Menaces pour IVIA |
|---|---|
| Pas de capacité documentaire — terrain libre | Base installée très large — migration lente |
| Pas de positionnement éthique données | Tarif bien inférieur à IVIA |
| Pas de formation praticien sur la doctrine | Praticiens habitués à Acuity résistent au changement |

**Positionnement relatif** : Acuity est un concurrent de logistique, pas d'accompagnement. Un praticien peut utiliser Acuity pour la prise de rendez-vous ET IVIA pour la documentation. La substitution directe est rare — mais la concurrence pour le budget tech du praticien est réelle.

**Différenciation IVIA** : IVIA n'est pas un outil de prise de rendez-vous. C'est un outil de pratique professionnelle. La documentation, la continuité et l'éthique des données sont des axes absents chez Acuity.

### 1.2 GOrendezvous

**Profil** : GOrendezvous est une plateforme québécoise de gestion de clinique et de prise de rendez-vous, orientée vers les professionnels de la santé et du mieux-être. Elle offre un module de téléconsultation (vidéo).

**Analyse SWOT — GOrendezvous**

| Forces | Faiblesses |
|---|---|
| Plateforme québécoise, conformité Loi 25 native | Aucune documentation IA de la séance |
| Orientée professionnels de la santé | Positionné logistique et gestion de clinique |
| Module téléconsultation vidéo | Pas de pipeline de données éthique documenté |
| Réseau de praticiens établi au Québec | Peu d'innovation sur l'expérience de séance |
| Tarification variée selon modules | Marketing orienté vers les cliniques, pas les praticiens solo |

| Opportunités | Menaces pour IVIA |
|---|---|
| Aucune capacité de synthèse documentaire | Présence établie dans les réseaux de santé québécois |
| Pas de doctrine éthique distinctive | Crédibilité "plateforme de santé" auprès des ordres |
| Vidéo = format général, pas de positionnement audio | Peut lancer un module de documentation IA |

**Positionnement relatif** : GOrendezvous est la référence de gestion logistique pour les cliniques de santé au Québec. IVIA cible les praticiens solo d'accompagnement émotionnel. La concurrence directe est limitée, mais la crédibilité institutionnelle de GOrendezvous auprès des ordres professionnels est un avantage concurrentiel dans les approches institutionnelles.

### 1.3 Jane App (Canadian competitor)

**Profil** : Jane est une plateforme canadienne (Vancouver) de gestion de clinique, téléconsultation et documentation pour les professionnels de la santé. Fortement adoptée au Canada anglais, présence croissante au Québec.

**Analyse SWOT — Jane App**

| Forces | Faiblesses |
|---|---|
| Plateforme canadienne, conformité PIPEDA | Pas de pipeline de données éthique public |
| Module de téléconsultation mature | Aucun positionnement doctrinal sur les données |
| Notes de séance intégrées (non IA) | Documentation non structurée par IA |
| Adoptée par de nombreux praticiens de santé | Interface complexe pour praticiens hors santé |
| Intégration avec les systèmes de santé provinciaux | Pas de positionnement audio-only |

| Opportunités | Menaces pour IVIA |
|---|---|
| Aucune doctrine éthique différenciante | Base installée massive au Canada |
| Pas de focus sur l'accompagnement émotionnel | Peut développer un module IA de documentation |
| Marché Québec sous-développé pour Jane | Ressources importantes pour copier le positionnement |

**Positionnement relatif** : Jane est un concurrent sérieux pour la Strate 2 (membres d'ordres de santé). Si Jane développe un module de documentation IA, c'est un risque concurrentiel direct. Surveiller attentivement.

### 1.4 Plateformes de bien-être généralistes au Québec (multiples)

**Mytaverne, Naître Bien, Thério, et autres**

Ces plateformes québécoises de bien-être proposent des séances de coaching, de méditation, ou de soutien émotionnel. Aucune n'a de pipeline documentaire structuré ni de positionnement éthique des données formalisé.

**Différenciation IVIA** : ces plateformes sont des marketplaces de praticiens. IVIA est une infrastructure de pratique. Ce ne sont pas des concurrents directs — ce sont des canaux potentiels de référencement vers IVIA.

## PARTIE II — CONCURRENTS ADJACENTS AU QUÉBEC

### 2.1 Téléconsultation en santé mentale

**Dialogue Health** (Toronto, présence Québec) : plateforme B2B de soins de santé mentale pour les employeurs. Services de psychologues et de counsellers par téléconsultation. Marché cible : les entreprises, pas les praticiens solo.

**Teladoc Health** : téléconsultation médicale avec modules de santé mentale. Orienté vers le marché médical réglementé.

**Différenciation IVIA** : ces acteurs ciblent les grandes entreprises et les systèmes de santé. IVIA cible les praticiens indépendants et leurs clients. Marchés distincts.

### 2.2 Plateformes de wellness corporatif

**Lyra Health, Calm for Business, Headspace for Work** : ces plateformes offrent du contenu de bien-être en volume pour les employeurs. Aucune relation 1:1 avec un praticien.

**Différenciation IVIA** : pas de concurrence directe. Ces plateformes pourraient devenir des partenaires (clients corporate qui utilisent à la fois Lyra pour le wellness général et IVIA pour les séances individuelles).

## PARTIE III — CONCURRENTS INTERNATIONAUX À SURVEILLER

### 3.1 BetterHelp (États-Unis)

**Profil** : la plus grande plateforme de thérapie en ligne au monde (~4 millions de clients, 30 000+ thérapeutes licenciés). Marketplace de thérapie à distance.

**Pourquoi surveiller** :
- BetterHelp a fait l'objet d'une amende de 7,8 millions USD de la FTC en 2023 pour avoir partagé des données de santé mentale à des fins publicitaires sans consentement adéquat
- Cet incident est une référence centrale pour le positionnement IVIA : "ce que nous ne ferons jamais, et voici pourquoi"
- BetterHelp a des ressources pour entrer sur le marché canadien

**Menace pour IVIA** : faible à court terme (BetterHelp opère dans les actes cliniques réglementés, hors périmètre IVIA direct). Menace pour la confiance générale dans les plateformes de soutien émotionnel en ligne (l'incident FTC fragilise tout le secteur).

**Opportunité pour IVIA** : l'incident BetterHelp est un argument de communication puissant. "IVIA construit ce que BetterHelp n'a pas su protéger."

### 3.2 Talkspace (États-Unis)

**Profil** : plateforme de thérapie par messagerie et vidéo. Controverses sur la qualité des soins et les pratiques de données.

**Menace pour IVIA** : similaire à BetterHelp — risque de contamination réputationnelle du secteur si de nouveaux scandales émergent.

### 3.3 Woebot Health et les chatbots thérapeutiques IA

**Profil** : Woebot est un chatbot de soutien en santé mentale fondé sur la thérapie cognitive-comportementale (TCC). Entièrement automatisé, sans praticien humain.

**Tendance** : explosion du marché des chatbots thérapeutiques IA. Investissements massifs dans ce sous-secteur (Woebot, Wysa, Youper, Spring Health, etc.).

**Menace pour IVIA** : menace indirecte à long terme. Si les chatbots thérapeutiques IA atteignent une qualité suffisante pour remplacer les séances avec un praticien humain dans une fraction des cas, le marché de l'accompagnement individuel se comprime.

**Réponse doctrinale IVIA** : IVIA est explicitement fondé sur la relation humaine praticien-client. L'IA de MERLIN structure et documente — elle ne remplace pas l'écoute humaine. La doctrine Principe 1 (le vivant d'abord) est une réponse à cette menace.

**Opportunité** : la fatigue des chatbots IA (frustration des utilisateurs face à des réponses génériques et superficielles) crée une demande accrue pour la relation humaine authentique. IVIA peut capitaliser sur ce retour au besoin d'écoute humaine réelle.

### 3.4 Gros acteurs IA entrant dans la santé mentale

**OpenAI, Google, Meta** ont tous des projets ou des partenariats dans le domaine de la santé mentale assistée par IA. Le risque est que l'un de ces acteurs lance une plateforme d'accompagnement émotionnel IA avec des ressources massives.

**Scénario de menace** : un acteur majeur (ex. Google DeepMind) lance un assistant d'accompagnement émotionnel IA, disponible gratuitement ou à très faible coût, avec une qualité comparable à MERLIN.

**Probabilité** : modérée à moyen terme (3-5 ans).

**Réponse IVIA** : le moat d'IVIA n'est pas la technologie IA seule (que les gros acteurs peuvent copier). C'est la combinaison de la doctrine, du pipeline de données gouvernées, du dataset synthétique, et de la relation de confiance avec les praticiens et les ordres professionnels. Un acteur comme Google ne peut pas revendiquer la non-commission et le pipeline J+30 sans détruire son propre modèle publicitaire.

## PARTIE IV — TENDANCES IA EN SANTÉ MENTALE ET ACCOMPAGNEMENT

### 4.1 Tendances observées (2024-2026)

**Tendance 1 — Multiplication des chatbots thérapeutiques**

Le marché des applications de santé mentale numérique était évalué à 5,6 milliards USD en 2023, avec une croissance projetée à 17,5 % par an. La quasi-totalité de cette croissance est tirée par les applications IA et les chatbots.

**Implication pour IVIA** : IVIA doit se positionner clairement comme différent de cette tendance, pas dans sa continuité. "Nous ne sommes pas un chatbot. Nous sommes l'infrastructure de l'écoute humaine, outillée par l'IA."

**Tendance 2 — Régulation croissante des applications de santé mentale numériques**

La FDA américaine (510k pour les applications de santé mentale), l'Agence européenne des médicaments, et la Commission européenne (Loi sur l'IA — classification "haut risque" pour certains outils de santé mentale) développent tous des cadres réglementaires plus stricts.

**Implication pour IVIA** : renforcement du positionnement non-clinique. IVIA n'est pas une application de santé mentale au sens réglementaire — c'est une infrastructure documentaire pour l'accompagnement. Cette distinction sera de plus en plus importante à maintenir.

**Tendance 3 — Demande croissante de transparence sur les données en santé**

Les scandales de données (BetterHelp, Babylon Health, etc.) créent une sensibilité croissante des utilisateurs et des praticiens à l'éthique des données. Les solutions qui peuvent démontrer leur transparence gagnent un avantage concurrentiel.

**Implication pour IVIA** : le rapport d'audit annuel public d'IVIA est un actif concurrentiel croissant, pas seulement un engagement éthique.

**Tendance 4 — Croissance de la télépratique professionnelle au Canada**

La pandémie a accéléré l'adoption de la télépratique. Les ordres professionnels ont adapté leurs règlements (ex. OPQ télépractice 2022). La télépratique n'est plus marginale — elle est une modalité standard.

**Implication pour IVIA** : le timing est favorable. La fenêtre d'opportunité pour s'établir comme infrastructure de référence pour la télépratique éthique est ouverte, mais pas indéfiniment.

## PARTIE V — RISQUES CONCURRENTIELS

### 5.1 Copie du positionnement doctrinal

**Risque** : un concurrent décide de copier la posture éthique d'IVIA — pipeline de données, non-commission, charte publique.

**Probabilité** : faible à court terme (coût de restructuration d'un modèle économique existant). Modérée à 3 ans si IVIA prouve la viabilité du modèle.

**Mitigation** : le moat d'IVIA n'est pas le positionnement déclaré (n'importe qui peut publier une "charte éthique"). C'est le pipeline technique réel, le dataset synthétique accumulé, et la confiance des praticiens et des ordres. Ces actifs prennent des années à construire.

**Réponse si cela se produit** : accélérer la construction du dataset synthétique et du modèle propriétaire. Le moat technologique propriétaire est plus difficile à copier que le positionnement déclaré.

### 5.2 Entrée d'un acteur bien financé

**Risque** : une startup bien capitalisée (ex. issue d'un fonds américain ou européen) entre sur le marché québécois avec un positionnement similaire et des ressources 10x supérieures.

**Probabilité** : faible à court terme (le marché québécois francophone est relativement niche pour les acteurs anglophones). Modérée à 3-5 ans.

**Mitigation** : les relations avec les ordres professionnels québécois, la conformité Loi 25 native, et la doctrine enracinée dans la culture québécoise de l'accompagnement créent des barrières à l'entrée réelles pour les acteurs extérieurs.

### 5.3 GOrendezvous ou Jane développent un module documentaire IA

**Risque** : un concurrent logistique établi au Québec lance un module de documentation IA, rendant son offre partiellement comparable à IVIA sur un axe clé.

**Probabilité** : modérée à 2-3 ans. La technologie est accessible (GPT-4.1 API). L'exécution est plus complexe, mais pas impossible.

**Mitigation** :
1. La doctrine et l'éthique des données ne sont pas replicables par un acteur orienté logistique commerciale
2. Les relations avec les ordres construites via la Strate 2 créent un avantage relationnel durable
3. L'avance sur le dataset synthétique et le modèle propriétaire crée un avantage technique croissant

## PARTIE VII — DIFFÉRENCIATION IVIA DURABLE (MOAT)

### 7.1 Les 5 couches du moat IVIA

**Couche 1 — Moat doctrinal (immédiat, non réplicable sans autodestruction)**

La règle de non-commission est structurellement incompatible avec le modèle économique des plateformes de mise en relation. La pipeline J+30 est structurellement incompatible avec la monétisation des données. Aucun concurrent dominant ne peut copier ces positions sans détruire sa propre source de revenus.

**Couche 2 — Moat réglementaire (construit sur 12-18 mois)**

Les conventions-cadres avec les ordres professionnels québécois créent une barrière relationnelle. Un concurrent qui arrive 24 mois après IVIA doit reconstruire ces relations depuis zéro, dans un contexte où IVIA est déjà la référence.

**Couche 3 — Moat données (construit sur 24-36 mois)**

Le dataset synthétique IVIA est unique. Il représente des milliers de patterns d'accompagnement émotionnel en français québécois, dans un cadre doctrinal cohérent. Ce dataset ne peut pas être reconstitué rapidement par un concurrent — il faut des années de séances et de pipeline pour l'accumuler.

**Couche 4 — Moat technologique (construit sur 36 mois)**

Le modèle propriétaire IVIA fine-tuné sur le dataset synthétique produit des analyses, synthèses et recommandations d'une précision et d'une pertinence que les modèles généralistes ne peuvent pas atteindre pour le domaine de l'accompagnement émotionnel.

**Couche 5 — Moat de confiance (construit sur 36 mois)**

La confiance des praticiens, des clients et des ordres professionnels est un actif qui ne se mesure pas en code ou en données. Elle se construit séance après séance, audit après audit, transparence après transparence. Elle est le moat le plus lent à construire et le plus difficile à détruire ou à copier.

### 7.2 Test du moat

Une question simple permet de tester la robustesse du moat IVIA : "Si OpenAI lançait demain une plateforme d'accompagnement émotionnel avec MERLIN-like features, IVIA survivrait-il ?"

Réponse : oui, pour les raisons suivantes :
1. OpenAI ne peut pas s'engager à ne jamais utiliser les données pour entraîner ses modèles sans violer son propre modèle économique
2. OpenAI ne peut pas construire des relations institutionnelles avec les ordres professionnels québécois en quelques mois
3. OpenAI ne peut pas produire un audit doctrinal annuel public car il n'a pas de doctrine publique opposable
4. Les praticiens et clients qui choisissent IVIA pour ses valeurs ne migreront pas vers une plateforme GAFAM pour les mêmes valeurs

## PARTIE VIII — SCÉNARIOS DE RÉACTION SI CONCURRENT AGRESSIF

### Scénario A — Concurrent prix-casseur (même service, prix 50 % inférieur)

**Réponse** :
1. Ne pas s'aligner sur le prix (trahirait la doctrine de l'échange équitable)
2. Démontrer la valeur différenciante (documentation de qualité, éthique des données, continuité)
3. Renforcer les actions de fidélisation des praticiens existants
4. Accélérer le développement du moat technologique pour creuser l'écart qualitatif

**Ce qu'on ne fait pas** : guerre des prix.

### Scénario B — Concurrent "greenwashing éthique" (copie du discours sans la doctrine)

**Réponse** :
1. Publier notre propre audit doctrinal annuel avec des preuves techniques vérifiables
2. Inviter le concurrent à un audit comparatif public
3. Renforcer l'argument : "La doctrine IVIA est opposable et auditée — ce n'est pas du marketing"

### Scénario C — Concurrent qui signe avec un ordre professionnel avant IVIA

**Réponse** :
1. Comprendre les conditions de l'accord (souvent moins exigeant qu'une convention-cadre IVIA)
2. Continuer à approcher l'ordre en proposant une collaboration complémentaire (pas exclusive)
3. Capitaliser sur les membres de l'ordre qui choisissent IVIA de façon indépendante
