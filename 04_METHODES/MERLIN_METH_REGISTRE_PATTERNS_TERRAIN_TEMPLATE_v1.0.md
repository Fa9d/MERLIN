# MERLIN - Registre patterns terrain template (v1)

Date: 2026-04-19
Statut: draft
Objet: gabarit pour suivre les phenomenes recurrents observes sur le terrain sans les transformer trop vite en verites generales

---

## 1) Usage

Ce registre sert a noter:
- ce qui revient souvent;
- ce qui bloque souvent;
- ce qui semble monter ou baisser;
- ce qui appelle une revision de methode.

Il ne sert pas a:
- generaliser a partir d'un cas;
- produire un discours populationnel premature.

Reference schema:
- `MERLIN_PREU_SCHEMA_PATTERN_TERRAIN_v1.0.md`

---

## 3) Regle

Un pattern n'est pas valide parce qu'il est frappant.

Il devient utile seulement si:
- il revient;
- il est formulable;
- il peut etre revise;
- il peut etre degrade.
